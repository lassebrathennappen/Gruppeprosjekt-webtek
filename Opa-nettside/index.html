This document describes the project requirements for the website of OPA!, a modern Greek restaurant located in Trondheim. The website is developed as part of the IT2805 Web Technologies course. The authors of this document are responsible for defining the functional and non-functional requirements for the project, as well as the overall structure and purpose of the website.
